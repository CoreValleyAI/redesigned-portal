1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
CoreValley is Nepal's sovereign AI cloud platform — NVIDIA H100 and H200
infrastructure hosted in Kathmandu, billed in NPR, with full in-country data
residency. The web portal is a Next.js 15 application covering:

  - Marketing website (public-facing, 9 pages)
  - Customer console / portal (authenticated, 13 pages)
  - Full mock data layer simulating the real backend

Stack: Next.js 15 (App Router) · React 19 · TypeScript 5.9 (strict) ·
Tailwind CSS v4 · CVA · Phosphor Icons

Platform Stack v2.1 context: This portal is Layer 5 (Customer Control Plane)
of the CoreValley platform. It sits on top of Layers 1-4 which run on HPE's
Kubernetes during the POC phase.
